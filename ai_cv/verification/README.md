# Verification

Verification khác unit test: nó chứng minh một phase đạt exit criteria bằng artifact hoặc metric thực tế.

## Required final checks

- Cấu trúc workspace đầy đủ.
- Dataset paths tồn tại và không bị sửa.
- Practice evaluation report có đủ 6 trip.
- Scored submission có đủ 10 trip x 1.800 frame.
- Model/config/version có truy vết.
- Robustness và latency report tồn tại.
- Output schemas parse được.
- Reproduction command chạy từ đầu.
